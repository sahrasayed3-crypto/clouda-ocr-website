Published Benchmark

Benchmark v0.1.0 Published · Historical

Released September 7, 2026. A completed, published evaluation of 177 distorted Arabic page images with 6 models achieving full 177/177 valid coverage. Results are specific to this benchmark and do not imply universal OCR performance.

What is measured

  • Task: page-level OCR on distorted Arabic document page images (photographic and rendering-style degradations: blur, compression, noise, skew, perspective, low resolution, contrast, shadow, faded paper, bleedthrough, combined profiles).
  • Primary metric: Normalized Arabic CER (lower is better) — character error rate after a deterministic Arabic normalization (NFC, alef/ya unification, tatweel and diacritic removal, whitespace collapse), averaged over each model's valid evaluated pairs.
  • Also reported: strict CER and WER. Error rates are not capped at 1.0 because insertion errors can make edit distance exceed reference length.
  • Runtime: contextual only — compared within the same hardware environment.

How results are anchored

  • Canonical manifest: 177 unique sample IDs define the benchmark registry and prevent silent subset drift.
  • Stored outputs: per-sample model outputs are stored; all aggregates were recomputed offline from them with the canonical evaluator — no inference was rerun.
  • Deterministic decoding: sampling disabled, batch size 1, fixed seed (20260825).
  • Integrity: SHA-256 checksums over the release, plus sanitization, license-review and consistency audit artifacts.

PaddleOCR-VL-1.6 failed its smoke run; its full benchmark run was never started, so it is unranked. Failure evidence is retained in the public release.

Benchmark expansion / Current evaluation

Current evaluation — 462 held-out pages In progress

An evaluation on 462 held-out Arabic pages across multiple OCR/VLM candidates is in progress and currently paused pending additional compute capacity. Results will be published only after the evaluation is complete.

Scope

462 held-out pages

Defined by a frozen manifest with a recorded SHA-256 checksum, prepared from pinned dataset revisions with documented provenance and licensing.

Plan

10-model evaluation plan

A model registry of 10 candidates with pinned revisions and documented OCR prompts. Evaluation follows the same stored-outputs, canonical-evaluator discipline as v0.1.0.

Status

Paused — pending compute

The run stopped in a controlled state with all completed work preserved; it resumes without recomputing finished pages once compute capacity is available.

Results: not published yet. No partial leaderboard, no interim winner, and no unvalidated metric claims will be shown for this evaluation. When complete, results will be validated and published separately from v0.1.0.
